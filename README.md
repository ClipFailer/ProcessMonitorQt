# Process Monitor (Qt6 C++20)

Высокопроизводительный, современный системный монитор процессов на **C++20** и **Qt 6**, спроектированный с акцентом на минималистичный дизайн, отзывчивость UI и низкое потребление собственных ресурсов (< 0.5–1.0% CPU).

---

## Ключевые возможности

### 1. Ядро сбора системных метрик (Backend Engine)
- **Общесистемная статистика:** суммарная нагрузка CPU (user/kernel/idle), использование физической RAM и файла подкачки (Swap/Pagefile), активность дисков (чтение/запись байт/сек) и сетевых интерфейсов (Rx/Tx).
- **Иерархическое дерево процессов:** распознавание связей `Parent PID -> Child PID`, автоматическая привязка процессов-сирот (orphans) к корню.
- **Детализация по процессам:**
  - Точный расчет CPU % через дельту `GetProcessTimes` к системным тикам, нормализованный по количеству ядер.
  - Память: Working Set (RSS), Private/Commit Bytes, пиковый размер памяти.
  - Дисковый ввод-вывод: счетчики I/O и мгновенная скорость передачи.
  - Количество активных потоков и открытых дескрипторов (Handles).
  - Разрядность (x86 / x64), путь к исполняемому файлу и аргументы командной строки (чтение PEB/NTAPI).
- **Управление процессами:** завершение (`TerminateProcess`), приостановка (`NtSuspendProcess`), возобновление (`NtResumeProcess`), изменение приоритета.
- **Поддержка платформ:** нативная реализация для **Windows** (`Toolhelp32`, `PSAPI`, `ntdll.dll`, `iphlpapi`) и **Linux** (быстрый парсинг `/proc` без динамических аллокаций).

### 2. Модуль углубленной инспекции (Deep Inspection)
- Список загруженных модулей и динамических библиотек (DLL / Shared Objects) с базовыми адресами и размерами.
- Список потоков процесса с Thread ID, приоритетами и временем выполнения в режимах User/Kernel.
- Детальные свойства процесса (аргументы запуска, пути, разрядность).

### 3. Пользовательский интерфейс и производительность (Frontend UI)
- **Точечное обновление модели (Smart Diff):** дерево процессов обновляется через `dataChanged()`, `beginInsertRows()` и `beginRemoveRows()` без вызова `resetModel()`, сохраняя раскрытые узлы, скролл и выделение.
- **Корректная сортировка:** столбцы сортируются по сырым числовым значениям (байты, проценты, ID), а не по строковым представлениям.
- **Живой поиск:** фильтрация по имени и PID с сохранением родительских узлов для видимости дочерних процессов.
- **Векторные Sparklines:** кастомный рендеринг графиков истории через `QPainter` со сглаживанием и градиентной заливкой без внешних тяжелых библиотек.
- **Цветовая подсветка активности:** плавный зеленый индикатор для новых процессов и красный для завершающихся.
- **Минималистичная тема:** дизайн в стиле Slate Dark (`#121214`) с аккуратными карточками и разделителями.

## Сборка и запуск

### Требования
- Компилятор с поддержкой **C++20** (GCC 12+, Clang 15+, MSVC 2022+ / MinGW-w64 13+)
- **CMake** версии 3.20 или новее
- **Qt 6** (компоненты `Core`, `Gui`, `Widgets`)
- Система сборки **Ninja** (рекомендуется)

### Сборка через командную строку (Windows / MinGW)
```bash
# Конфигурация проекта
cmake -B build -G Ninja -DCMAKE_BUILD_TYPE=Release -DCMAKE_PREFIX_PATH="C:/QT/6.8.0/mingw_64"

# Компиляция
cmake --build build

# Запуск тестов
ctest --test-dir build --output-on-failure

# Запуск приложения
./build/ProcessMonitor.exe
```
